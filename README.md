## О проекте

**AI Exam Assistant** — веб-приложение, которое превращает разрозненные учебные материалы студента (PDF-лекции, конспекты, статьи, ссылки, видео) в интерактивные тесты для подготовки к сессии. Система сама генерирует вопросы по загруженным материалам, проверяет ответы (включая открытые), выставляет оценку по шкале 2–5, объясняет ошибки и подсказывает, что и в каком порядке повторить.

## Структура
backend - серверная часть приложения
frontend - клиентская часть приложения
ml - ИИ сервис обработки
tests - тесты

## Быстрый старт


### 1. Клонировать репозиторий

```bash
git clone https://ssau.saas.sferaplatform.ru/app/sourcecode/api/tp_ivt_team5_2026/tp_ivt_team5_2026.git
cd tp_ivt_team5_2026
```

### 2. Настроить окружение

```bash
cp .env.example .env
# Отредактировать .env — указать API-ключи LLM, пароли БД
```

### 3. Запустить всё через Docker Compose

```bash
docker compose up -d --build
```
